# Usage

```python
import signal_processing_recommender
```

Each module is self-contained; see docstrings for the API:

- `signal_processing_recommender.recommender` — Main entry point for the recommender system
- `signal_processing_recommender.signal_processing` — Module containing signal processing functions and classes
- `signal_processing_recommender.recommendation_engine` — Similarity-based recommendation engine implementation
- `signal_processing_recommender.data_loader` — Module responsible for loading audio and sensor waveform data
- `signal_processing_recommender.tests_test_recommender` — Unit tests for the recommender system
- `signal_processing_recommender.core` — main domain logic and public entry points
